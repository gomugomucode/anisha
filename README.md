# Asset Requirements

Please place your professional profile picture and resume file in this directory with the following filenames:

1. **Profile Picture**: Save your photo as `profile.jpg` in this directory. 
   - Recommended size: `340px` width by `380px` height (or similar aspect ratio).
2. **Resume**: Save your PDF file as `resume.pdf` in this directory.

Once these files are in place, the links and profile picture on your website will automatically load them.
